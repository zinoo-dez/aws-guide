<section id="business-problem">
  <h2>1. Business Problem & Context</h2>
  <p>
    An engineering organization with 120 developers noticed their monthly AWS bill creeping up by 15% each month. Developers frequently terminated EC2 test instances while leaving expensive 1TB gp3 EBS volumes attached to nothing, left unassociated Elastic IPs generating hourly fees, and neglected idle staging RDS databases running over long holidays.
  </p>
</section>

<section id="requirements-constraints">
  <h2>2. Requirements & Constraints</h2>
  <ul>
    <li><strong>Automated Waste Detection</strong>: Identify orphaned EBS volumes and unused IPs within 15 minutes of creation.</li>
    <li><strong>Safe Remediation</strong>: Snapshot orphaned EBS disks before deletion so no developer data is permanently lost.</li>
    <li><strong>Developer Notifications</strong>: Send interactive Slack warnings before terminating idle resources.</li>
  </ul>
</section>

<section id="implementation">
  <h2>6. Implementation Highlights</h2>
  <DeepDiveAccordion title="AWS Config Managed Rules for FinOps" badge="Rule Catalog">
    <ul>
      <li><code>ec2-volume-inuse-check</code>: Checks whether EBS volumes are attached to running EC2 instances.</li>
      <li><code>eip-attached</code>: Verifies whether Elastic IP addresses are allocated to active network interfaces.</li>
