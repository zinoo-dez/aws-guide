<section id="business-problem">
  <h2>1. Business Problem & Context</h2>
  <p>
    An international enterprise publishes technical articles in 6 languages. Using traditional origin servers for language detection caused severe latency spikes for European and Asian users. Additionally, enterprise compliance mandated strict security headers (Content Security Policy, HSTS, X-Frame-Options) across all static assets.
  </p>
</section>

<section id="requirements-constraints">
  <h2>2. Requirements & Constraints</h2>
  <ul>
    <li><strong>Automatic Geo/Language Redirection</strong>: Route users to <code>/es/</code>, <code>/de/</code>, <code>/ja/</code> without hitting the S3 origin.</li>
    <li><strong>A+ Security Rating</strong>: Inject HSTS, CSP, and XSS protection headers on every response.</li>
    <li><strong>Zero Origin Latency Penalty</strong>: Edge compute execution overhead must be under 2ms.</li>
  </ul>
</section>

<section id="implementation">
  <h2>6. Implementation Highlights</h2>
  <DeepDiveAccordion title="Security Headers Injection CloudFront Function" badge="Edge Code">

```
function handler(event) {
  var response = event.response;
  var headers = response.headers;

  headers['strict-transport-security'] = { value: 'max-age=63072000; includeSubDomains; preload' };
  headers['content-security-policy'] = { value: "default-src 'self'; img-src 'self' data: https:; script-src 'self';" };
  headers['x-content-type-options'] = { value: 'nosniff' };
  headers['x-frame-options'] = { value: 'DENY' };
  headers['referrer-policy'] = { value: 'strict-origin-when-cross-origin' };

  return response;
}
```

<section id="takeaways">
  <h2>8. Key Architectural Takeaways</h2>
  <blockquote>
    <strong>Edge Compute Rule:</strong> Use CloudFront Functions for ultra-fast, stateless header and URL transformations. Reserve Lambda@Edge only when your edge logic requires external HTTP calls or complex libraries.
