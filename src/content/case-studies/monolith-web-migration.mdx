<section id="business-problem">
  <h2>1. Business Problem & Context</h2>
  <p>
    An established e-learning company hosted their monolithic Django application on a single large on-premise virtual machine. Whenever traffic surged during exams or flash sales, the server froze. Furthermore, user sessions were stored in local server memory, meaning rebooting or patching the server forcibly logged out all active students.
  </p>
</section>

<section id="requirements-constraints">
  <h2>2. Requirements & Constraints</h2>
  <ul>
    <li><strong>Zero Downtime During Deployments</strong>: Eliminate maintenance maintenance windows.</li>
    <li><strong>Multi-AZ Fault Tolerance</strong>: Survive an entire AWS Availability Zone failure.</li>
    <li><strong>Stateless Compute</strong>: Externalize user sessions and file uploads.</li>
    <li><strong>Minimal Code Refactoring</strong>: Must run existing Django codebase without rewriting into microservices.</li>
  </ul>
</section>

  <ol>
    <li><strong>Session Externalization</strong>: Configured Django session backend to store sessions in Amazon ElastiCache Redis cluster.</li>
    <li><strong>Asset Offloading</strong>: User-uploaded media files were redirected from local disk storage to an Amazon S3 bucket.</li>
    <li><strong>Golden AMI & Launch Template</strong>: Automated image baking with Packer/EC2 Image Builder, enabling new instances to boot and pass ALB health checks in under 3 minutes.</li>
    <li><strong>Auto Scaling Target Tracking</strong>: ASG automatically adds instances when average CPU utilization exceeds 65%.</li>
  </ol>

<section id="implementation">
  <h2>6. Implementation Highlights</h2>
  <DeepDiveAccordion title="EC2 Launch Template User Data Script" badge="Automation">

```
#!/bin/bash
# Fetch latest app bundle from S3
aws s3 cp s3://app-deployments/django-latest.tar.gz /app/bundle.tar.gz
cd /app && tar -xzf bundle.tar.gz
# Inject DB & Redis credentials from SSM Parameter Store
export DATABASE_URL=$(aws ssm get-parameter --name "/prod/db_url" --with-decryption --query "Parameter.Value" --output text)
export REDIS_URL=$(aws ssm get-parameter --name "/prod/redis_url" --query "Parameter.Value" --output text)
# Start Gunicorn server
gunicorn app.wsgi:application --bind 0.0.0.0:8000 --workers 4
```

</DeepDiveAccordion>

<section id="takeaways">
  <h2>8. Key Architectural Takeaways</h2>
  <blockquote>
    <strong>Monolith Rule:</strong> You do not need to rewrite your application into microservices to achieve high availability. Externalizing session state and local file storage allows any legacy monolith to scale horizontally across multiple AZs.
  </blockquote>
