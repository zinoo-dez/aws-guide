<section id="business-problem">
  <h2>1. Business Problem & Context</h2>
  <p>
    A high-growth enterprise CRM SaaS serves over 5,000 corporate clients (tenants). Early in their growth, a software developer forgot to include <code>WHERE tenant_id = ?</code> in a raw SQL query, causing Tenant A to view confidential customer deals belonging to competitor Tenant B.
  </p>
</section>

<section id="requirements-constraints">
  <h2>2. Requirements & Constraints</h2>
  <ul>
    <li><strong>Zero Software-Layer Cross-Tenant Data Leaks</strong>: Enforce isolation at the infrastructure/IAM layer rather than relying on developer application code.</li>
    <li><strong>Tiered Isolation Models</strong>: Pooled multi-tenant architecture for Starter tiers ($99/mo); dedicated Silo database instances for Enterprise tier customers ($10,000/mo).</li>
    <li><strong>Per-Tenant Resource Metering</strong>: Calculate exact monthly AWS compute, storage, and API costs per client.</li>
  </ul>
</section>

```
{

  "Statement": [{
    "Effect": "Allow",
    "Action": ["dynamodb:GetItem", "dynamodb:PutItem", "dynamodb:Query"],
    "Resource": "arn:aws:dynamodb:us-east-1:123456789:table/saas_pooled_data",
```
